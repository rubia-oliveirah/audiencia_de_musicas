# 🎵 Audiência de Músicas

## 📌 Sobre o projeto

Este projeto foi desenvolvido em linguagem C com o objetivo de simular a quantidade de reproduções de 10 músicas de um artista. O programa utiliza o algoritmo **Bubble Sort** para organizar os dados em ordem crescente e decrescente.

## 🎯 Objetivos

- Trabalhar com vetores em linguagem C.
- Praticar estruturas de repetição (`for`).
- Aplicar o algoritmo Bubble Sort.
- Organizar e exibir dados em diferentes ordens.

## ⚙️ Funcionalidades

- Exibe a quantidade original de reproduções das 10 músicas.
- Organiza os valores em ordem crescente.
- Organiza os valores em ordem decrescente.
- Apresenta os resultados no terminal.
